# The Useless Vibe 🎲

Your next five-minute rabbit hole: tiny browser games you probably haven’t played.

**[Find a game →](https://abhidya.github.io/theuselessvibe/)**

- **Surprise yourself.** Hit Play random, then explore with Previous, History and Next.
- **Find your vibe.** Browse by stars, or search and filter.
- **Bring a friend.** Share a room code for the same game order. Everyone plays at their own pace.

No account. No install. Just one more game.

Some games won’t embed; choose **More → Open directly**. Rooms share discovery, not multiplayer gameplay.

## Run locally

```sh
python3 -m http.server 8000 --directory site
```

Open [localhost:8000](http://localhost:8000). See [development and tests](docs/DEVELOPMENT.md) for collection, validation and browser checks.
