This is a doorway to the overlooked web: small experiments, playful projects, and unexpected places built by people making things.

We look for game-related phrases in little-known MIT repositories, exclude forks, and check the GitHub Pages links we find. You can follow the phrase that catches your eye, or leave the next discovery to chance. A matching phrase is a clue, so the results can include more than games.

Codex activity and Claude credit filters use public commits and pull requests. Follow the evidence links to see each match; it doesn’t establish who wrote the whole project.

What do the filters check?

Website matches come from the fetched page’s HTML text; words rendered only in a canvas or by JavaScript may be missed. README matches come from the repository’s README. Selecting several phrases matches any of them. Agent activity checks cover a limited recent history, and an unmarked project may still have used an agent.
